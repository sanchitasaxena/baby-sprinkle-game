# Guess the Baby

A static baby sprinkle quiz for Valeriia and Nicola. Play it at:

https://sanchitasaxena.github.io/baby-sprinkle-game/

The game runs entirely in the browser and does not require Cloudflare or
another backend.

## Don't peek

The photos use anonymous filenames, but the quiz needs an answer key to run.
That mapping is intentionally stored in `frontend/Don't Peek/answers.js`.
Opening that folder will spoil the game.
